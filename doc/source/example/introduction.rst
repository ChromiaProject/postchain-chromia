Learn by an example: The city tracker
######################################

In this section you can learn how to set up your on blockchain network by studying an concrete example. The example project is called "The city tracker".

The cluster has four nodes. Bc0 is set up on the first node and also added by the management client (postchain-mc) so that bc0 will become aware of itself. Then we can in a convenient  way update configuration, add a second blockchain to be managed by bc0: ``city``. More nodes can optionally be added and be made signers. This sample provides configurations for up to 4 nodes.
